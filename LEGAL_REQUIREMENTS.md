# Legal Requirements for Production Launch

## IMMEDIATE (Must have before ANY public launch)

### 1. Privacy Policy
**Required disclosures:**
- What data you collect (email, presentations, documents, Google tokens)
- How you use it (AI processing, storage, analytics)
- Third parties with access (Google, Gemini API, hosting providers)
- User rights (GDPR: access, deletion, portability, rectification)
- Data retention periods (how long you keep deleted data)
- International transfers (if using US servers with EU users)
- Cookie usage (if any analytics)
- Contact information for data requests

**Where to add:**
- `frontend/src/pages/Privacy.jsx`
- Link in footer, signup flow, settings
- Require acceptance on first login

### 2. Terms of Service
**Required terms:**
- Acceptable use (no illegal content, malware, abuse)
- Intellectual property (who owns generated presentations)
- Liability limitations (AI can make mistakes, you're not liable)
- Service availability (no uptime guarantees for free tier)
- Account termination conditions
- Dispute resolution / jurisdiction
- Changes to terms notification

**Where to add:**
- `frontend/src/pages/Terms.jsx`
- Require acceptance on signup
- "By using SlideMind you agree to our Terms"

### 3. GDPR Compliance Implementation

**Data Subject Rights - Required Endpoints:**
```python
# Must implement:
POST /api/user/data-export  # Download all user data as JSON
POST /api/user/delete-account  # Permanent deletion (GDPR right to erasure)
GET /api/user/data-usage  # What data you have on them
```

**Consent tracking:**
```python
# Add to User model:
privacy_policy_accepted_at = db.Column(db.DateTime)
privacy_policy_version = db.Column(db.String(16))
terms_accepted_at = db.Column(db.DateTime)
terms_version = db.Column(db.String(16))
marketing_consent = db.Column(db.Boolean, default=False)
```

**Cookie banner (if you add analytics):**
- Non-essential cookies require explicit consent
- Must work without accepting (functional-only mode)

### 4. AI-Specific Disclosures

**Required under EU AI Act (coming 2025):**
- "Content generated by AI" watermark/notice
- Disclosure that Gemini processes user content
- Model limitations and potential errors
- No guarantee of factual accuracy

**Add to frontend:**
```jsx
// In presentation view:
"⚠️ AI-Generated Content - Verify facts before use"
```

### 5. Image Licensing Compliance

**Current risk:**
- You use Unsplash/Pexels images
- Unsplash: Attribution required for commercial use
- Pexels: Free but check their ToS for AI use

**Required:**
```python
# Add to image metadata:
{
  "source": "unsplash",
  "photographer": "John Doe",
  "license": "Unsplash License",
  "attribution_required": true
}
```

**Display in exports:**
"Images from Unsplash (photographer credits in notes)"

### 6. Google OAuth Disclosures

**Required by Google:**
- Privacy Policy covering Google data usage
- Explicit scope descriptions ("Why we need Drive access")
- Data deletion instructions
- Limited Use disclosure (if using restricted scopes)

**Update consent screen:**
"SlideMind will access your Google Slides and Drive to create and publish presentations. We never access other files."

## IMPORTANT (Required for paid plans / scale)

### 7. Content Policy & Moderation
- Define prohibited content (hate speech, illegal, NSFW)
- Abuse reporting mechanism
- Automated content scanning (basic keyword filter)

### 8. Data Retention Policy
**Current problem:** You never delete anything
```python
# Add cron job:
- Delete guest accounts after 7 days inactive
- Delete failed uploads after 30 days
- Anonymize deleted user data after 90 days (keep for fraud)
```

### 9. Payment Terms (when you monetize)
- Refund policy
- Billing disputes
- Payment processor disclosures (Stripe/PayPal)
- Subscription cancellation terms

### 10. Export Control Compliance
**If deploying globally:**
- Gemini API has export restrictions (check Google's terms)
- May need geo-blocking for sanctioned countries
